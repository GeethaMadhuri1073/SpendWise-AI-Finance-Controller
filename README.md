# SpendWise AI – Intelligent Finance Controller

## 🚀 Overview

SpendWise AI is an AI-powered finance controller designed to help users understand their spending behaviour, monitor budgets, detect unusual transactions, and receive intelligent financial insights.

## 🎯 Problem Statement

Managing personal finances can be difficult because users may not easily identify overspending, suspicious transactions, or future spending patterns.

SpendWise AI addresses this problem using Machine Learning and financial analytics.

## ✨ Key Features

- Financial transaction analysis
- AI-based anomaly detection using Isolation Forest
- Suspicious transaction identification
- Expense prediction using Random Forest Regression
- 30-day expense forecasting
- Budget monitoring
- Personalized financial recommendations
- Financial Health Score
- Spending category analysis

## 🤖 AI Models Used

### Isolation Forest

Used to identify unusual or suspicious financial transactions based on transaction amounts.

### Random Forest Regressor

Used to analyze historical spending data and generate future expense predictions.

## 🧠 Financial Health Score

The Financial Health Score evaluates:

- Budget usage
- Suspicious transactions
- Spending concentration
- Overall spending behaviour

The system provides a score between **0 and 100** along with a financial risk status.
